# Asistente-inteligente-para-el-cultivo-de-chile-habanero
Aplicación web con técnicas de inteligencia artificial, mediante la búsqueda heurística A*, lógica difusa y redes neuronales convolucionales (CNN), para apoyar la planificación de rutas de inspección, la recomendación del tiempo de riego y la identificación visual de posibles enfermedades en el cultivo de chile habanero.
